# RecVoiceNow · V2.2.0

**Save any sound on your iPhone in seconds.**

Private voice & ambient recorder. Same navy + gold design language as FindJob Now.

**© 2026 Rafat Kotaki. All rights reserved.**

## Design
- Deep navy background (`#07111f`)
- Bright gold primary actions (`#f5c400`)
- Gold-bordered cards
- Clean white typography
- Mobile-first, large touch targets

## Features
- Voice & ambient (room/speaker) recording
- Dedicated iPhone “Other Apps” import flow
- Local library with search
- EN / JP
- PWA + Share Target
- Optional live transcription

## Deploy
Push folder contents to the GitHub repo root. No build step.
